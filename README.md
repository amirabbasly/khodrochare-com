# خودرو چاره — وب‌سایت رسمی

وب‌سایت «خودرو چاره»؛ مرکز امداد خودرو و خدمات خودرو در محل در تهران (شبانه‌روزی).

## خدمات

- تعمیر خودرو در محل
- پنچرگیری در محل
- خودروبر و یدک‌کش
- باتری در محل
- برق خودرو در محل
- سرویس دوره‌ای و خدمات خودرو در محل

## تماس

- خط ویژه امداد: ۰۹۱۲۳۰۲۲۰۶۴
- مرکز خودرو چاره: ۰۲۱۸۲۸۰۱۰۴۳

## توسعه

```bash
npm install
npm run dev
```

سپس [http://localhost:3000](http://localhost:3000) را در مرورگر باز کنید.

- تصاویر و لوگو در `public/images` قرار دارند (`logo.webp` لوگوی اصلی، `fleet.webp` ناوگان، `center.webp` نمایندگی مجاز، `workshop.webp` کارگاه مرکز، و آیکون‌های تصویری خدمات در `public/images/icons`).
- متن‌ها و اطلاعات تماس در `src/lib/data.ts` متمرکز شده‌اند تا ویرایش آن‌ها ساده باشد.

## تبلیغات و ردیابی (Google Ads / Analytics)

سایت برای کمپین‌های تبلیغاتی آماده است. کافی است شناسه‌های گوگل را در فایل `.env.local` قرار دهید (در Vercel از بخش Settings → Environment Variables):

```bash
NEXT_PUBLIC_GTM_ID=GTM-XXXXXXX
NEXT_PUBLIC_GA_ID=G-XXXXXXXXXX
```

رویدادهای تبدیل (Conversion) به‌صورت خودکار به دیتالیر گوگل ارسال می‌شوند:

- `call_click` — کلیک روی هر دکمه تماس تلفنی (همراه شماره تماس)
- `service_select` — انتخاب یک خدمت از کارت‌های خدمات
- `service_request` — ثبت موفق فرم درخواست خدمت (همراه نوع خدمت)
- `review_submit` — ثبت موفق فرم رضایت مشتری (همراه امتیاز و خدمت)
