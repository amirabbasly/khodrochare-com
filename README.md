# خودرو چاره — وب‌سایت رسمی

وب‌سایت «خودرو چاره»؛ مرکز امداد خودرو و خدمات خودرو در محل (شبانه‌روزی).
شعار: **یک تماس، یک چاره**

## خدمات

- تعمیر خودرو در محل
- پنچرگیری در محل
- خودروبر و یدک‌کش
- باتری در محل
- برق خودرو در محل
- سرویس دوره‌ای و خدمات خودرو در محل

## تماس

- خط ویژه امداد: ۰۲۱۹۱۸۵۵
- مرکز خودرو چاره: ۰۲۱۸۲۸۰۱۰۴۳

## توسعه

```bash
npm install
npm run dev
```

سپس [http://localhost:3000](http://localhost:3000) را در مرورگر باز کنید.

- تصاویر و لوگو در `public/images` قرار دارند (`logo.webp` لوگوی اصلی، `fleet.webp` ناوگان، `center.webp` مرکز).
- متن‌ها و اطلاعات تماس در `src/lib/data.ts` متمرکز شده‌اند تا ویرایش آن‌ها ساده باشد.
